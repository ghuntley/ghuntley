### g'day, i'm geoff 👋

I spend my days pondering the ponderoos about using AI in unhinged ways, and then verifying the outcomes at [@antithesishq](https://github.com/antithesishq).

I'm a software engineer who writes about AI-assisted software development.

- I created the **[Ralph loop](https://ghuntley.com/ralph/)**, which runs a coding agent in a loop until the work is done. It's the technique [loop engineering](https://ghuntley.com/loop/) grew out of.
- I defined **[agent back pressure](https://ghuntley.com/pressure/)**: letting compilers, tests and type checkers push back on an agent's output so it corrects itself.

I write from Kangaroo Island, Australia 🦘 at **[ghuntley.com](https://ghuntley.com)**.

#### 🔁 Ralph
- [**how-to-ralph-wiggum**](https://ghuntley.com/ralph): the Ralph Wiggum Technique. `while :; do cat PROMPT.md | agent ; done`, plus everything I've learned about running that loop well.
- [**cursed**](https://cursed-lang.org): 💀 a programming language built by Ralph. Programming, but make it gen z.

#### 🛠️ Build your own agent
- [**how-to-build-a-coding-agent**](https://github.com/ghuntley/how-to-build-a-coding-agent): a workshop where you build a coding agent from scratch. Once you see how it works, the magic goes away and you get better at driving the tools.

#### 🧰 Things I've shipped recently

- [**underclass**](https://github.com/ghuntley/underclass): an OpenAI-compatible pooling proxy that keeps prompt caches warm and cools down exhausted subscriptions.
- [**preflight**](https://github.com/ghuntley/preflight): a local proxy that scans LLM requests and attachments for secrets before they reach the model.
